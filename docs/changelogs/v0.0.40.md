### Features

* **Tabby**: Re-export [`Tabby`](../api/models/foundation/models.md#timecopilot.models.foundation.tabby) from `foundationforecast>=0.1.17` for Huawei Paris Noah's Ark Lab's [`paris-noah/Tabby`](https://huggingface.co/paris-noah/Tabby) ([arXiv:2609.13956](https://arxiv.org/abs/2609.13956)), a ~147M prompted patch transformer with 99 native quantiles (0.01–0.99). Follows the published inference path with a `precision` option (`"bf16"` autocast on CUDA by default). Loads with `trust_remote_code`; weights are CC BY-NC 4.0. See [#397](https://github.com/TimeCopilot/timecopilot/pull/397).

* **TimeH2O**: Re-export [`TimeH2O`](../api/models/foundation/models.md#timecopilot.models.foundation.timeh2o) from `foundationforecast>=0.1.16` for H2O.ai's [`timeh2o-v1`](https://huggingface.co/h2oai/timeh2o-v1) and [`timeh2o-v1-tiny`](https://huggingface.co/h2oai/timeh2o-v1-tiny) checkpoints (`h2ofm>=0.43.0`, Python 3.12+), with `clip_nonnegative` / `snap_integer` options matching the published benchmark runs. The checkpoints are gated and released under a non-commercial license. See [#397](https://github.com/TimeCopilot/timecopilot/pull/397).
