### Features

* **CIProto**: Re-export [`CIProto`](../api/models/foundation/models.md#timecopilot.models.foundation.ciproto) from `foundationforecast>=0.1.21` for Continuous Intelligence's [`ContinuousIntelligence/ci-proto`](https://huggingface.co/ContinuousIntelligence/ci-proto), a ~167M zero-shot probabilistic forecaster with a 16,384-step context and nine native quantiles (0.1 to 0.9), so `level` up to 80 and `quantiles` in that range need no conformal calibration (wider levels need `prediction_intervals=ConformalIntervals(...)`). CIProto needs the `continuousintelligence` package, installed with the new optional extra `pip install "timecopilot[ci-proto]"`; `timecopilot.models.foundation` imports without it and constructing the model without the extra raises an `ImportError` with the install command.

### Documentation

* **CIProto family notebook**: Added [`ci-proto-family` example notebook](../examples/ci-proto-family.ipynb) forecasting with CIProto, its native 80% intervals, conformal 95% intervals and cross-validation. ci-proto's native quantile grid stops at 0.9, so levels above 80 need `ConformalIntervals`.
* **Model hub**: List CIProto with its license and install extra.

### Dependencies

* **FoundationForecast**: Require `foundationforecast>=0.1.21` (CIProto wrapper and finite-sample conformal intervals).
* **`ci-proto` extra**: New optional extra that installs `foundationforecast[ci-proto]`.
