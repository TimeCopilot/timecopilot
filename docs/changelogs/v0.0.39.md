### Features

* **Timestral**: Re-export [`Timestral`](api/models/foundation/models.md#timecopilot.models.foundation.timestral) from `foundationforecast>=0.1.15` for Mistral's [`Timestral-5M/28M/123M/209M`](https://huggingface.co/collections/mistralai/timestral) checkpoints (`timecopilot-timestral>=0.1.0`). Native known-future covariates, 21 quantile knots with interpolation, and benchmark-aligned defaults `symmetric_averaging=True` / `clip_nonnegative=True`.

* **T0 gamma**: The existing `T0` class documents and supports [`theforecastingcompany/t0-gamma`](https://huggingface.co/theforecastingcompany/t0-gamma) via `foundationforecast>=0.1.15` (`tfc-t0[torch]>=0.6.0`).

### Documentation

* **Timestral family notebook**: Added [`timestral-family` example notebook](../examples/timestral-family.ipynb) comparing all four Timestral checkpoints.
* **T0 family notebook**: Updated [`t0-family` example notebook](../examples/t0-family.ipynb) for t0-gamma and `tfc-t0[torch]>=0.6.0`.
* **Model hub**: List Timestral, Tafsut, and t0-gamma with current dependency notes.

### Dependencies

* **FoundationForecast**: Require `foundationforecast>=0.1.15` (Timestral wrapper and t0-gamma support).
