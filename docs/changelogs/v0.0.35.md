### Features

* **PatchTST-FM family checkpoints**: Document and compare IBM Research and Granite PatchTST-FM releases via the existing `PatchTSTFM` class (`foundationforecast>=0.1.8`, `granite-tsfm>=0.3.8`). Pass `repo_id` to select the checkpoint:

    - `ibm-research/patchtst-fm-r1` (default) — [CC-BY-NC-SA-4.0](https://huggingface.co/ibm-research/patchtst-fm-r1) (non-commercial research weights)
    - `ibm-granite/granite-timeseries-patchtst-fm-r1` — [Apache-2.0](https://huggingface.co/ibm-granite/granite-timeseries-patchtst-fm-r1)
    - `ibm-granite/granite-timeseries-patchtst-fm-r2` — [Apache-2.0](https://huggingface.co/ibm-granite/granite-timeseries-patchtst-fm-r2) / [OpenMDW 1.0](https://openmdw.ai/license/1-0/) (dual-licensed; commercial-friendly)

    ```python
    import pandas as pd
    from timecopilot.models.foundation.patchtst_fm import PatchTSTFM

    df = pd.read_csv(
        "https://timecopilot.s3.amazonaws.com/public/data/air_passengers.csv",
        parse_dates=["ds"],
    )

    model = PatchTSTFM(
        repo_id="ibm-granite/granite-timeseries-patchtst-fm-r2",
        alias="Granite-PatchTST-FM-r2",
        context_length=2048,
    )
    fcst_df = model.forecast(df, h=12, freq="MS", level=[80, 90])
    ```

    **License note:** Only the IBM Research checkpoint (`ibm-research/patchtst-fm-r1`) is non-commercial ([CC-BY-NC-SA-4.0](https://huggingface.co/ibm-research/patchtst-fm-r1)). Granite PatchTST-FM r1 and r2 use permissive open licenses suitable for commercial use (see model cards above).
