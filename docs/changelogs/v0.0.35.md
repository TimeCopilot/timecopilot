### Features

* **PatchTST-FM family checkpoints**: Document and compare IBM Research and Granite PatchTST-FM releases via the existing `PatchTSTFM` class (`foundationforecast>=0.1.7`). Pass `repo_id` to select the checkpoint:

    - `ibm-research/patchtst-fm-r1` (default)
    - `ibm-granite/granite-timeseries-patchtst-fm-r1`

    ```python
    import pandas as pd
    from timecopilot.models.foundation.patchtst_fm import PatchTSTFM

    df = pd.read_csv(
        "https://timecopilot.s3.amazonaws.com/public/data/air_passengers.csv",
        parse_dates=["ds"],
    )

    model = PatchTSTFM(
        repo_id="ibm-granite/granite-timeseries-patchtst-fm-r1",
        alias="Granite-PatchTST-FM-r1",
        context_length=2048,
    )
    fcst_df = model.forecast(df, h=12, freq="MS", level=[80, 95])
    ```

    **License note:** PatchTST-FM weights are [CC-BY-NC-SA-4.0](https://huggingface.co/ibm-research/patchtst-fm-r1) (non-commercial).
