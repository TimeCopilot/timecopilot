### Documentation

* **Zensical**: The docs build with [Zensical](https://zensical.org/) and are published with the rest of the TimeCopilot docs at [docs.timecopilot.dev](https://docs.timecopilot.dev/timecopilot/). The contributing guide explains the build and its Python 3.11 requirement. See [#388](https://github.com/TimeCopilot/timecopilot/pull/388).
* **Example notebooks**: Every notebook starts with a `uv` install cell. See [#389](https://github.com/TimeCopilot/timecopilot/pull/389).
* **README**: Logos are served from the repo at matching sizes. See [#387](https://github.com/TimeCopilot/timecopilot/pull/387).
* **Model hub**: Fix a broken Prophet link.

### Tooling

* **Unified docs deploys**: Pushes to `main` and release tags trigger the [TimeCopilot/docs](https://github.com/TimeCopilot/docs) build, which replaces this repo's own docs deploys. See [#385](https://github.com/TimeCopilot/timecopilot/pull/385) and [#386](https://github.com/TimeCopilot/timecopilot/pull/386).
* **Docs dependencies**: The `docs` group replaces MkDocs Material and its plugins with `zensical` and `mkdocstrings-python`, adds `griffe-inherited-docstrings`, and drops `modal`.
