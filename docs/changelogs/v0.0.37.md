### Dependencies

* **SciPy (Python 3.11+)**: Require `scipy>=1.17.1` when running on Python 3.11 or newer (`uv.lock` resolves 1.17.1 on 3.11 and 1.18.1 on 3.12+).
* **SciPy (Python 3.10)**: Keep `scipy<=1.15.3` on Python 3.10 via environment markers (SciPy 1.17+ does not publish 3.10 wheels). Project support for Python 3.10 is unchanged.
