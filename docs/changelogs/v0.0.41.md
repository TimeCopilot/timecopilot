### Features

* **Kumo**: Re-export [`Kumo`](../api/models/foundation/models.md#timecopilot.models.foundation.kumo) from `foundationforecast>=0.1.20` for NVIDIA's [`nvidia/Kumo-Forecast`](https://huggingface.co/nvidia/Kumo-Forecast) ([Kumo-TS](https://github.com/NVIDIA/Kumo-TS)), a ~340M zero-shot forecaster with a 512-step context and a 72-step native horizon (longer horizons roll forward autoregressively). Kumo produces point forecasts only: `level` and `quantiles` raise a `ValueError` unless the model is created with `prediction_intervals=ConformalIntervals(...)` from `foundationforecast`, which calibrates intervals from cross-validation errors.

### Documentation

* **Kumo family notebook**: Added [`kumo-family` example notebook](../examples/kumo-family.ipynb) forecasting with Kumo and adding conformal prediction intervals and cross-validation.
* **Model hub**: List Kumo with its point-forecast-only behavior and license.

### Dependencies

* **FoundationForecast**: Require `foundationforecast>=0.1.20` (Kumo wrapper).
